# 법인카드 집근처 사용 분석

법인카드 사용내역 엑셀과 이용자 집 주소를 넣으면, 카카오 지도로 가맹점 위치를 찾아 **집에서 일정 반경 안에서 쓴 내역**을 골라내는 웹 도구입니다.
모든 처리는 브라우저 안에서만 이뤄지고, 카드 데이터는 서버로 전송되지 않습니다. 카카오에는 주소 문자열만 보냅니다.
AI 요약·보고서를 쓸 때만 Gemini로 최소한의 정보가 전송됩니다 (아래 6번 참고).

## 1. 처음 한 번만: 카카오 키 준비

1. [카카오 디벨로퍼스](https://developers.kakao.com/console/app) → 애플리케이션 추가
2. **앱 설정 > 플랫폼 > Web**에 사이트 도메인 `http://localhost:8080` 등록
3. **카카오맵** 서비스 사용 설정을 **ON**으로 켜기 (꺼져 있으면 지도와 주소 검색이 동작하지 않습니다)
4. **앱 키 > JavaScript 키** 복사

## 2. 실행

`start.bat`을 더블클릭하면 로컬 서버가 뜨고 브라우저가 `http://localhost:8080`으로 열립니다. (Python 필요)

```bash
python -m http.server 8080
```

처음 열면 오른쪽 위 **설정**에 JavaScript 키를 붙여넣고 저장합니다.

## 3. 사용 순서

1. **카드 사용내역 불러오기**: 회사 양식 엑셀/CSV를 끌어다 놓습니다.
   - 필수 컬럼: 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소
   - 상단에 제목 줄이 있어도 헤더 행을 자동으로 찾습니다. CSV는 UTF-8과 EUC-KR 모두 읽습니다.
2. **이용자 집 주소**: 이용자마다 집 주소를 입력합니다.
   - `이용자명,집주소` 형식의 CSV/엑셀로 한 번에 가져올 수 있습니다 (`sample/집주소_샘플.csv` 참고).
   - 주소로 위치를 못 찾으면 📍 버튼을 눌러 지도에서 직접 찍습니다.
3. **분석 기준**을 정하고 **분석 실행**을 누릅니다.
   - 반경: 100m~5km (기본 1km). 분석 후 슬라이더를 움직이면 바로 다시 계산합니다.
   - 심야 시간: 기본 22시~06시
   - 공휴일: 2025~2026년 목록이 들어 있으며, 직접 고칠 수 있습니다. 주말은 자동으로 포함됩니다.

## 4. 결과 화면

| 영역 | 내용 |
|---|---|
| 요약 지표 | 분석 대상, 집 근처 사용(건수·금액·금액 비중), **집 근처 + 휴일·심야**, 위치 확인 불가 건수 |
| 지도 | 집(🏠)과 반경 원, 가맹점 위치(빨강: 반경 내 / 파랑: 반경 밖). 점을 클릭하면 그 가맹점의 사용내역이 나옵니다 |
| 이용자별 요약 | 집 근처 사용 비중, 휴일·심야 건수. 행을 클릭하면 그 이용자로 필터합니다 |
| 거리별 사용 건수 | 집에서의 거리 구간별 사용 건수 |
| 상세 내역 | 판정 태그, 정렬, 검색, 필터. 행을 클릭하면 지도에서 해당 위치를 보여줍니다 |
| 결과 엑셀 저장 | 원본 18개 컬럼 + 거리, 집근처 여부, 휴일, 심야, 판정, 제외 사유, 위치 정확도 |

### 판정 기준

- **집근처**: 가맹점이 집에서 설정 반경 이내
- **집근처·휴일/심야** (가장 주의): 집 근처이면서 주말·공휴일이거나 심야 시간
- **분석 제외**
  - 해외·주소없음: 미화금액이 있거나 국내 주소가 아닌 경우
  - 온라인·PG: 업종명에 PG/온라인/통신판매 등이 들어간 경우. 가맹점 주소가 결제대행사 본사라 실제 사용 위치가 아닙니다. 설정에서 끌 수 있습니다.
  - 집주소 미등록 / 가맹점 위치 미확인

## 5. 이상징후 탐지

분석 결과 위쪽 **이상징후 탐지 결과** 카드에 규칙별 건수·금액이 나옵니다. 카드를 누르면 상세 내역이 그 거래만 보이도록 걸러지고, 결과 엑셀에는 `이상징후` 컬럼이 붙습니다.

| 심각도 | 유형 | 기준 |
|---|---|---|
| 높음 | 집 근처 + 휴일·심야 | 집 반경 내에서 주말·공휴일 또는 심야에 사용 |
| 높음 | 분할결제 의심 | 같은 이용자·가맹점·날짜에 10분 안에 2건 이상 (온라인 제외) |
| 중간 | 집 근처 반복 이용 | 집 반경 내 같은 가맹점을 3회 이상 |
| 중간 | 고액 결제 | 1건이 고액 기준 이상 (기본 500,000원, 카드 위에서 변경) |
| 중간 | 심야 사용 | 심야 시간 승인 (집 근처 건 제외) |
| 낮음 | 휴일 사용 | 주말·공휴일 사용 (집 근처 건 제외) |

## 6. AI 요약 · 경영진 보고서 (Gemini)

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Gemini API 키를 발급합니다.
2. 오른쪽 위 **설정 > Gemini AI 설정**에 키를 넣고 **연결 확인**을 누르면 쓸 수 있는 모델 목록이 채워집니다. 비워 두면 최신 Flash 모델(예: `gemini-3.8-flash`)을 자동으로 고르고, 구글이 모델을 종료해 404가 나면 다른 모델로 바꿔 다시 시도합니다.
3. 분석 후 화면 맨 아래 **AI 분석 · 보고서**에서
   - **이상징후 요약**: 한눈에 보기, 유형별 이상징후, 우선 확인 대상 표, 확인 질문 예시
   - **경영진 보고서 작성**: 개요 표, 핵심 요약, 주요 지표, 이상징후 분석, 이용자별 현황, 리스크 평가, 권고 조치
4. 결과는 **복사**, **Word 저장(.doc)**, **인쇄 / PDF**로 내보낼 수 있습니다.

**Gemini로 보내는 정보**: 집계 수치와 이상징후 거래의 일자·시간·가맹점명·업종·금액·지역(시·구)·집까지 거리.
카드번호·승인번호·사업자번호·상세주소·집주소는 보내지 않습니다. 이용자명은 기본적으로 `직원01` 같은 가명으로 바꿔 보내고, 받은 결과에서 실명으로 되돌립니다.

> 무료 등급 API 키는 입력 내용이 Google 서비스 개선에 쓰일 수 있습니다. 회사 데이터 반출 정책을 확인한 뒤 사용하세요.
> AI 결과는 초안입니다. 수치와 사례는 원자료와 대조한 뒤 활용하세요.

### 주소 → 좌표 변환 방식

카드 내역의 주소는 `서울 강남구 테헤란로 281 효성빌딩 10층`처럼 건물명·층수가 붙어 있어 그대로 검색하면 실패하는 경우가 많습니다. 그래서 아래 순서로 찾습니다.

1. 도로명 + 건물번호까지만 잘라 검색 (`서울 강남구 테헤란로 281`)
2. 지번 주소 형태로 검색 (`서초동 1670 15` → `서초동 1670-15`)
3. 원문 주소로 키워드 검색
4. 끝에서부터 단어를 하나씩 줄여 도로/동 단위로 검색 → 상세 내역에 **근사** 표시

찾은 좌표는 브라우저에 저장해 두고 다음 분석부터 다시 조회하지 않습니다. 설정에서 **주소 좌표 캐시 비우기**로 지울 수 있습니다.

## 파일 구성

```
card-home-analyzer/
├─ index.html     화면
├─ style.css      스타일
├─ app.js         파싱 · 지오코딩 · 분석 · 지도 · 내보내기
├─ ai.js          이상징후 탐지 · Gemini 요약 · 경영진 보고서
├─ vendor/        SheetJS (엑셀 읽기, 오프라인용)
├─ start.bat      로컬 서버 실행
└─ sample/집주소_샘플.csv
```

## 참고

- 카카오 JavaScript 키는 등록한 도메인에서만 동작합니다. 사내 서버에 올릴 때는 그 서버 주소도 카카오 디벨로퍼스에 추가로 등록해야 합니다.
- 집 주소, 카카오 키, Gemini 키, 좌표 캐시는 그 PC 브라우저의 localStorage에만 저장됩니다.
- 엑셀 읽기용 SheetJS는 `vendor/`에 들어 있고, 없을 때만 CDN에서 불러옵니다.
