카카오 지도 설정

  1. 카카오 디벨로퍼스에서 애플리케이션을 만듭니다.
  2. [플랫폼 > Web]에 사이트 도메인 을 등록합니다.
  3. [카카오맵] 서비스 사용 설정을 ON으로 켭니다.
  4. JavaScript 키를 위 칸에 붙여넣고 저장합니다.

Gemini AI 설정

모델
  • 키 발급: Google AI Studio → API 키 만들기
  • [연결 확인]을 누르면 쓸 수 있는 모델 목록을 불러와 최신 Flash 모델을 골라 줍니다. 비워 두면 자동으로 고릅니다.
  • 구글이 모델을 종료하면 다른 모델로 자동 전환해 다시 시도합니다.
  • 키는 이 브라우저에만 저장됩니다. 무료 등급 키는 입력 내용이 Google 서비스 개선에 쓰일 수 있으니 회사 정책을 확인하세요.
